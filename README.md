Robotic Arm

Past project involving a robotic arm with servo and hydraulic actuation.

3 joints: shoulder, elbow, and wrist, with a gripper at the end
Able to rotate 180° and pick up small objects at various heights
Safety indicator light that turns on when the arm is in motion, along with a display showing "MOTION!"
Sonar sensor programmed to detect changes in motion regardless of whether the arm is actuated by the servo or hydraulic system
